# AquaGuru - Smart Shrimp Farm Management System

![AquaGuru Logo](https://via.placeholder.com/200x100?text=AquaGuru)

## 🚀 Overview

AquaGuru is a comprehensive web-based shrimp farm management system built with Python Flask, MySQL, and Bootstrap 5. It provides farmers with tools to monitor and manage their shrimp farming operations efficiently.

## ✨ Features

### 🏠 Dashboard
- Real-time farm statistics
- Interactive charts and graphs
- Recent activity feed
- Notification center

### 🌊 Pond Management
- Add/Edit/Delete ponds
- Track pond details (area, seed count, species)
- Monitor pond status

### 🍽️ Feed Calculator
- Calculate biomass and daily feed requirements
- Save feed records
- View feed history

### 💧 Water Quality
- Record water parameters (pH, DO, temperature, etc.)
- Get status indicators (Good/Moderate/Poor)
- View recommendations for improvements

### 📈 Growth Tracking
- Monitor DOC, ABW, ADG, Survival %, FCR
- Visual growth charts
- Historical data tracking

### 💰 Expense Management
- Categorize expenses (Feed, Medicine, Labour, etc.)
- Daily/Monthly/Total expense tracking
- Expense distribution charts

### 📦 Inventory Management
- Track feed, medicine, and supplies
- Low stock alerts
- Supplier management

### 🌾 Harvest Management
- Record harvest data
- Calculate income and profit
- Harvest performance analysis

### 🔔 Notifications
- Feed reminders
- Water test reminders
- Harvest reminders
- Low stock alerts

### 🤖 AI Assistant
- Get instant advice on shrimp farming issues
- Low DO solutions
- High ammonia treatment
- White gut management
- FCR optimization

### 👤 Farmer Profile
- Edit profile information
- Change password
- Farm details management

### 📊 Reports
- Feed Consumption Report
- Growth Performance Report
- Expense Analysis Report
- Water Quality Report
- Harvest Results Report
